# エンジニアの役割概要

Webシステムの構成とエンジニアの役割を図解したリポジトリです。

## 図解一覧

### 1. クライアント・サーバモデル

複数のクライアント端末（PC・タブレット・スマートフォン）がサーバに対してリクエストを送り、レスポンスを受け取る基本的な仕組みを示します。

![クライアント・サーバモデル](client-server-model.svg)

---

### 2. 各エンジニアの担当領域

クライアント・サーバモデルを踏まえ、フロントエンドエンジニア・バックエンドエンジニア・インフラエンジニアがそれぞれどの領域を担当するかを示します。

![各エンジニアの担当領域](engineer-roles.svg)

---

### 3. スマホの登場とエンジニアの広がり

スマートフォンの普及により、クライアント側にiOSエンジニア・Androidエンジニアという役割が加わった経緯と、サーバ側（バックエンド・インフラ）はWeb・スマホアプリで共通して使われることを示します。

![スマホの登場とエンジニアの広がり](smartphone-engineers.svg)
