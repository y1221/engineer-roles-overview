## エンジニアの役割概要

#### 0. クライアント・サーバモデル

前提として、Webアプリケーション（＝Webサービス／Webシステム）は、「クライアント・サーバモデル」で構築されている
- Webアプリケーション：Webブラウザを使って操作するアプリケーション
- クライアント・サーバモデル：無数のクライアント端末（PC・タブレット・スマートフォン）が、1つのサーバと通信する仕組み

![クライアント・サーバモデル](client-server-model.svg)

#### 3. [参考] デスクトップアプリケーション
PCで利用するアプリケーションの中には、Webアプリケーションの他にも、デスクトップアプリケーションたるものがある。
こいつは、スタンドアロンモデルであることが多い
- デスクトップアプリケーション：インストールが必要なアプリケーション。固有のウインドウを使って操作する
- スタンドアロンモデル：画面もデータ・ロジックも一つの端末上で完結する

⚠️補足
- デスクトップアプリケーションの中には、サーバが用意されていて、裏で通信するものもある（結構一般的。この場合はスタンドアロンでないので、ハイブリッド型）
- デスクトップアプリケーション開発を担うエンジニアを指す言葉は**ない**。（技術的にはバックエンドが中心になるので、「バックエンドエンジニアですね〜」と言うことが多いし、それで話が噛み合わないことはない）

#### 最後に補足
「Webアプリケーション」や「デスクトップアプリケーション」というのは、あくまで提供形態の一種

⇒例えば、Slackは、Webアプリ・デスクトップアプリ（ハイブリッド型）・モバイルアプリと、様々な形態でサービス提供している
